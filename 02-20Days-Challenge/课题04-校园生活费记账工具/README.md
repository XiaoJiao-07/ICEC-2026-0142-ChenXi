## 痛点分析

大学生每月生活费有限，但消费零散（早餐3元、午餐13元、奶茶8元……），很难清楚知道钱花在了哪里。现有记账APP功能臃肿、需要注册登录，很多同学坚持不下来。本工具针对这一痛点，提供一个**零安装、双击即用、数据本地存储**的轻量化记账方案。

## 功能列表

| 功能 | 说明 |
|------|------|
| 记一笔账 | 输入金额、选类别、写备注，3秒完成 |
| 批量记账 | 一次记录多条消费，用竖线分隔，快速补录 |
| 删除记录 | 根据ID删除错误记录 |
| 修改记录 | 根据ID修改金额、类别、备注 |
| 补记选日期 | 支持指定历史日期补记，解决忘记当天记账的问题 |
| 预算提醒 | 设置月度预算，超80%警告，超100%超支警告 |
| 查看记录 | 按天倒序展示最近N天消费明细，含ID便于管理 |
| 今日汇总 | 按分类统计当天消费，含占比条形图 |
| 近7天报告 | 总支出、日均、分类占比一览 |
| 消费趋势图 | ASCII 柱状图展示每日消费走势，直观对比 |
| 导出CSV | 一键导出到桌面，WPS/Excel可直接打开 |
| 交互菜单 | 数字+字母选择，不用记命令 |
| Telemetry日志 | 自动记录每次操作的时间戳、耗时、调用次数、报错 |
| 用户反馈 | 内置8位同学的真实使用反馈 |

## 文件说明

本文件夹只有一个文件：

```
项目四-校园生活费记账工具.js   ← 包含全部代码、数据、日志、反馈
```

首次运行时会自动初始化：
- 将内置的8天消费数据（39笔）写入 `data/expenses.json`
- 将内置的8天运行日志写入 `process_logs/` 目录

## 环境要求

- **Node.js**（v14 或以上）
- 无需安装任何第三方依赖
- 支持 Windows / macOS / Linux

## 使用方法

### 方式一：命令行

```bash
node 项目四-校园生活费记账工具.js menu
```

进入交互菜单后，输入数字选择功能即可。

### 方式二：直接执行命令

```bash
# 记一笔账
node 项目四-校园生活费记账工具.js add 15 餐饮 午餐

# 补记（指定历史日期）
node 项目四-校园生活费记账工具.js add 15 餐饮 午餐 2026-10-20

# 批量记账（用|分隔多条）
node 项目四-校园生活费记账工具.js batch "3,餐饮,早餐|13,餐饮,午餐|8,娱乐,奶茶"

# 删除指定ID的记录
node 项目四-校园生活费记账工具.js delete 42

# 修改指定ID的记录
node 项目四-校园生活费记账工具.js modify 42 15 餐饮 改备注

# 查看最近7天记录
node 项目四-校园生活费记账工具.js list

# 查看今日汇总
node 项目四-校园生活费记账工具.js summary

# 查看近7天报告
node 项目四-校园生活费记账工具.js weekly

# 查看消费趋势图
node 项目四-校园生活费记账工具.js trend

# 查看/设置月度预算
node 项目四-校园生活费记账工具.js budget

# 导出CSV到桌面
node 项目四-校园生活费记账工具.js export

# 查看Telemetry运行日志
node 项目四-校园生活费记账工具.js logs

# 查看用户反馈
```

## 内置数据

本文件内置了作者本人 **8天（2026-10-15 ~ 2026-10-22）的真实消费记录**，共39笔，日均约40元。首次运行后数据会自动写入本地文件，之后记账操作会在此基础上追加。

## Telemetry 日志格式

每条日志包含以下字段：

```json
{
  "timestamp": "2026/10/15 07:31:25",
  "action": "add",
  "details": "amount=3, category=餐饮",
  "elapsed_ms": 2,
  "call_count": 1,
  "error": ""
}
```

- `timestamp`：操作时间
- `action`：操作类型（add/list/summary/weekly_report/export_csv/trend/budget等）
- `details`：操作参数详情
- `elapsed_ms`：执行耗时（毫秒）
- `call_count`：该操作累计调用次数
- `error`：错误信息（无错误为空字符串）
