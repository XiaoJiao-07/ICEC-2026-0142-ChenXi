## 痛点分析

大学生每月生活费有限，但消费零散（早餐3元、午餐13元、奶茶8元……），很难清楚知道钱花在了哪里。现有记账APP功能臃肿、需要注册登录，很多同学坚持不下来。本工具针对这一痛点，提供一个**零安装、双击即用、数据本地存储**的轻量化记账方案。

## 功能列表

## 使用方法

### 方式一：双击启动

双击 `记账.bat` 即可进入交互菜单。

### 方式二：命令行

```bash
node app.js menu
```

### 方式三：直接执行命令

```bash
# 记一笔账
node app.js add 15 餐饮 午餐

# 批量记账
node app.js batch "3,餐饮,早餐|13,餐饮,午餐|5,餐饮,买水"

# 删除记录
node app.js delete 5

# 修改记录
node app.js modify 5 20 购物 新备注

# 查看最近7天记录
node app.js list

# 查看今日汇总
node app.js summary

# 查看近7天报告
node app.js weekly

# 查看消费趋势图
node app.js trend

# 设置月度预算
node app.js budget 1000

# 查看预算使用情况
node app.js budget

# 补记消费（指定日期）
node app.js addbackdate 15 餐饮 2026-10-20 补记午餐

# 导出CSV到桌面
node app.js export

# 查看Telemetry运行日志
node app.js logs

# 查看用户反馈
node app.js feedback

# 查看消费数据
node app.js data
```

## 消费数据（基线）

作者本人 **8 天（2026-10-15 ~ 2026-10-22）的真实消费记录**共 39 笔，日均约 40 元，存放在 `raw_data/baseline_2026-10.csv`。

**说明（务必分清两件事）**：

1. **记录端是逐日的**——这 39 笔当时逐日记在手机备忘录里，当天花完就记一条；
2. **入库端是一次性的**——10-22 为提交材料，才把这批记录一次性整理进源码常量 `SEED_DATA`，并导出 CSV。

所以问题是**入库方式不合规**（事后一次性整理、且形式是源码常量），而不是数据内容不真实。由于它出现在仓库里时已看不出逐日过程，**仅作为个人消费基线，不计入"运行时日志"评分项**。来源、性质与佐证状态详见 `raw_data/baseline_README.md`。

2026-11-09 起 `SEED_DATA` 已从源码移除，改为独立 CSV；新的记账数据由程序运行时逐笔写入 `data/expenses.json`，与基线分开。

## Telemetry 日志格式

每条日志为一行 JSON（JSONL），字段如下：

```json
{
  "seq": 3,
  "ts": "2026-11-09 19:17:42.318",
  "ts_utc": "2026-11-09T11:17:42.318Z",
  "date": "2026-11-09",
  "action": "add",
  "details": { "amount": 13, "category": "餐饮" },
  "elapsed_ms": 5,
  "error": "",
  "prev_hash": "a3f1...",
  "hash": "9c02..."
}
```

- `seq`：当日序号，从 1 开始，必须连续
- `ts` / `ts_utc`：系统真实时间（本地时区含毫秒 / UTC）
- `action`：操作类型（startup/add/batch_add/delete/modify/list/summary/weekly_report/monthly/trend/budget/export_csv 等）
- `elapsed_ms`：执行耗时（毫秒）
- `error`：错误信息（无错误为空字符串）
- `prev_hash`：前一条记录的 SHA-256（当日首条为 `GENESIS`，跨日不断链）
- `hash`：本条记录内容的 SHA-256

**写入方式**：仅 `appendFileSync(path, line, { flag: 'a' })` 追加，全流程无 `writeFileSync` 覆盖日志。任一行的任一字段被改动，`hash` 立即不匹配，且后续所有行的 `prev_hash` 全部断裂。

**校验方式**：

```bash
node src/verify_chain.js    # 输出 [PASS] 并打印链头；异常时打印具体行号与原因
node src/selfcheck.js       # 每日提交前自查：日志存在/时间戳真实/链完整/当日已提交/commit 锚定链头
```
