## 二、我的假设（可被证伪）

### H1（并列文件是首因）

> 用户点错，是因为顶层同时存在 `node.exe` 与 `记账.bat` 两个可点击对象，而前者的视觉重量远大于后者。

**若成立**：把 `node.exe` 移进子目录、顶层只留一个可点击文件、并给它一个像按钮的名字之后，**新用户首次双击就进入程序的比例应从 1/3 升到 ≥ 2/3**，且不再出现"打不开/找不到入口"这类表述。

### H2（文件夹本身就是首因）

> 真正的问题不是"选错文件"，而是"面对一个文件夹不知道要干什么"——即使只剩一个可点击文件，用户仍会犹豫、乱点、或先双击文件夹里的其他东西。

**若成立**：改动之后，仍有新用户在门口停顿超过 30 秒，或去点 `使用说明.txt` / 进 `data` 文件夹翻找。

### 判据（数据前写定，不可事后调整）

接下来 **2 位**新用户，同一句指令、全程不提示、不指屏幕，只记录三个数：

| 观察项 | 记录方式 | 判定为 H1 成立 | 判定为 H2 成立 |
|---|---|---|---|
| 第一次双击的文件 | 文件名，逐字 | 2/2 命中启动脚本 | 任一人点错 |
| 从坐下到菜单出现 | 秒（以录屏/截图时间戳为准） | ≤ 15 秒 | > 30 秒 |
| 门口相关原话 | 逐字 | 无"打不开/找不到" | 出现同类表述 |

**两种假设不互斥的可能性已预先承认**：H1 成立而 H2 也部分成立（点对了文件但仍犹豫）在 ITER-002 里刚发生过一次，这次不预设"只能二选一"。

### 这条假设可能失败的地方（预先写明）

1. **两位新用户可能都已经被作者口头说过"点那个 bat"** → 那样数据作废，必须记 0/0 而不是记成功
2. 用户可能把整个文件夹拷到自己电脑（异机），路径变化会让 `.bat` 里的相对路径出错 → 需一并记录
3. 改动后仍有人双击 `runtime/` 里的 `node.exe` → 说明"藏起来"不够，得改成不可双击（H2 变体）

## 三、改了什么

**改动时间：2026-11-14 22:41–22:50**（假设在 22:48 之前已写好并提交 `f06a9f1`；本节的改动在假设之后执行）。

### 3.1 改动前后（用户副本顶层）

**改前**：

```
node.exe          ← 103 MB，程序图标
记账.bat          ← 142 字节，默认图标
app.js  main.js  src/  data/  process_logs/  使用说明.txt
```

**改后**：

```
①双击我记账.bat    ← 顶层唯一可点击的文件，158 字节
runtime/          ← 只装运行环境，node.exe 搬进来了
  node.exe
app.js  main.js  src/  data/  process_logs/  使用说明.txt
```

**顶层已经没有任何 `.exe`。** 用户扫一眼，只有一个能点。

### 3.2 启动脚本 diff

```diff
- 记账.bat
+ ①双击我记账.bat

 @echo off
 chcp 65001 >nul
 cd /d "%~dp0"
-if exist "%~dp0node.exe" (
-  "%~dp0node.exe" app.js menu
+if exist "%~dp0runtime\node.exe" (
+  "%~dp0runtime\node.exe" app.js menu
 ) else (
   node app.js menu
 )
 pause
```

`.bat` 内容**全 ASCII**、CRLF 换行——中文路径 + UTF-8 bat 在部分系统上会把 `%~dp0` 解析错，这一点刻意规避：**文件名可以是中文，脚本内容不行。**

### 3.3 `使用说明.txt` 同步改两行

| 行 | 改前 | 改后 |
|---|---|---|
| 第 2 步 | 双击「记账.bat」 | 双击「**①双击我记账.bat**」 |
| 运行环境说明 | 「那个 node.exe 是运行环境，别删、别改名」 | 「那个 runtime 是运行环境，**不用点它**、也不用管它」 |

### 3.4 `app.js` 一行未动

这次迭代**只改打包方式**，不改代码。理由：H1 说的是"并列文件造成误点"，如果同时改了菜单，下次验证就无法归因。**一次只动一个变量**，是 ITER-002 给我的教训（那次两个假设同时成立，裁决差点失效）。

### 3.5 自测（不算验证）

在母版目录用管道喂入 `0`（退出），验证两件事：

```
$ printf '0\n' | cmd //c "①双击我记账.bat"

============================
  1. 记一笔        2. 最近记录      3. 今日汇总
  ...
请输入序号: 再见！
```

- **菜单能起来** → 相对路径 `runtime\node.exe` 正确
- **中文目录名 + 中文 bat 名可执行** → 双击场景无编码问题

自测产生的 `process_logs/telemetry_2026-11-14.log` 已删除，**母版保持零日志零账目**，避免污染下一位用户的首条 `GENESIS`。

### 3.6 未采用的做法

| 方案 | 为什么不采用 |
|---|---|
| 把 `node.exe` 改名为 `node_运行环境_请勿点击.exe` | 仍然是顶层 `.exe`，图标不变，还是最像"该点"的那个；只是把说明写在了它脸上 |

| 顺便修 P7（日期）或 P8（记完无下一步） | 一迭代一变量；P7 留给 ITER-004 |
