# 第二次测量（Run 2）实验说明

## 一、为什么要做第二次测量

Run 1（2026-10-21）只做了**一次**测量，得到端到端效率 79.9%、输出效率 73.9%。
单次测量无法区分两种情况：

- 79.9% 是充电宝的真实效率；
- 79.9% 里混入了偶然误差（起始电量判读、指示灯状态的时点偏差、环境温度、手机后台负载）。

**任何一次实验结论都必须能复现。** 因此本实验在不改变任何硬件条件的前提下，独立重做一遍，用于：

1. 检验 Run 1 的效率是否能复现（这是结论成立的前提）；
2. 用两次结果的差异给出**误差范围**，替代原先"按 3/4 颗灯折算"的单点粗估；
3. 若两次结果接近，说明原报告的计算方法可用，问题只在"未放空"这一项表述；若差异大，则以两次的区间为准重新表述。

> **本实验不修改 Run 1 的任何原始数据**，Run 1 记录表 `discharge_log.csv` 保持原样。

## 二、与 Run 1 的区别（必须如实记录）

| 项目 | Run 1 | Run 2 |

## 三、操作步骤

1. **先把充电宝充满**（指示灯 4 灯全亮，不再闪烁），静置 10 分钟；
2. **手机正常用到 20%~30% 左右**（不必刻意放到 5%，如实记录即可）；
3. 开始充电的同时开始计时，记下 **开始时刻**（精确到分钟）；
4. 每 10 分钟记录一次：`时间_min`（从 0 开始，0/10/20…）、`手机电量_%`（锁屏界面读数）、`充电宝指示灯`（4灯/3灯/2灯/1灯/灭）；
5. 手机显示 100% 时记为最后一组，记录 **总时长**，实验结束；
6. 注意事项（对应 Run 1 的已知缺陷，这次必须避免）：
   - 充电期间**手机保持息屏、不玩游戏、不播放视频**（Run 1 未说明后台负载，这是不确定来源之一）；
   - **每隔 10 分钟看一次电量的动作本身会点亮屏幕**，请看完立刻熄屏，并在备注里写明这一点，作为已知扰动；
   - 指示灯变化要记录**发生变化的那个采样点**，不要事后回填。

## 五、填完之后的处理

记录表填完后**不要自己改数**。把 CSV 和照片一起提交，由分析脚本统一计算：

- 充入能量 `E = 手机电池能量 23.34 Wh × (结束% − 起始%) / 100`
- 平均充入功率 `P = E / (总时长 / 60)`
- 与 Run 1 的 7.0 W 平均功率、79.9% 端到端效率对比
