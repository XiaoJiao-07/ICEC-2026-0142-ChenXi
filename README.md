## 项目概览

本项目包含三个课题，展示了从问题发现、方案设计到代码实现的完整过程。

### 01-Field-Discovery（领域发现）

#### 课题02：手机发热掉电实测
- **问题**: 手机在不同使用场景下发严重、电量消耗快
- **成果**: 
  - 24组实测数据（CSV格式）
  - 分析报告（Markdown）
  - 实测照片与截图（9 个文件）
- **文件**: `01-Field-Discovery/课题02-手机发热掉电实测/`
- **证据说明**: 测试时序、数据有效性判定与已知局限见该报告第七节

#### 课题07：充电宝标称容量与转换效率核验
- **问题**: 充电宝标称容量与实际输出不符
- **成果**:
  - 放电测试日志（CSV）
  - 核验报告（Markdown）
  - 实测照片（3 张，含本人与设备同框实拍）
- **文件**: `01-Field-Discovery/课题07-充电宝标称容量与转换效率核验/`
- **证据说明**: 分段效率估算的误差范围与未完成项见该报告第十节

### 02-20Days-Challenge（20天挑战）

#### 课题04：校园生活费记账工具
- **痛点**: 大学生消费零散，难以掌握资金流向
- **解决方案**: 轻量化命令行记账工具，零安装、双击即用
- **核心功能**:
  - 记账/批量记账/删除/修改
  - 日/周/月统计报表
  - 预算提醒与异常消费提醒
  - 消费趋势图（ASCII可视化）
  - 补记功能（支持指定日期）
  - 数据导出（CSV/JSON备份）
  - 运行时遥测日志（append-only 追加 + SHA-256 哈希链，2026-11-09 起逐日产生）
- **技术栈**: Node.js（原生实现，无第三方依赖）
- **文件结构**:
  ```
  课题04-校园生活费记账工具/
  ├── main.js          # 核心程序
  ├── app.js           # CLI入口+交互菜单
  ├── 记账.bat         # 桌面快捷方式
  ├── README.md        # 项目说明
  ├── user_feedback.md # 8位用户反馈
  ├── src/
  │   ├── telemetry.js      # append-only 遥测写入 + 哈希链
  │   ├── verify_chain.js   # 哈希链校验（可检出任意改动）
  │   └── selfcheck.js      # 每日提交自查
  ├── process_logs/    # 遥测日志（运行时逐条追加）
  ├── raw_data/        # 原始消费数据（基线 CSV + 原始表）
  └── data/            # 本地存储（不上传）
  ```
- **使用方法**:
  ```bash
  # 交互菜单
  node app.js menu
  
  # 或直接双击 记账.bat
  
  # 查看帮助
  node app.js help
  ```

## 数据与证据说明

本仓库 2026-10-15 ~ 2026-10-22 期间的**部分材料存在记录方式问题**（内容真实但非逐日运行产生），已在 [`CORRECTION.md`](CORRECTION.md) 中逐项披露。请结合该文件阅读，不要仅凭文件名或 README 表述推断证据性质。

| 材料 | 性质 | 说明 |
|---|---|---|
| `raw_data/baseline_2026-10.csv`（39 笔） | 内容真实；逐日记于备忘录（本人陈述），一次性入库 | 本人真实消费；原始载体已不可追溯，**无截图等佐证**，故不可被第三方核验。入库方式为 10-22 一次性整理进源码常量 |
| `raw_data/consumption_raw.csv` | 同源导出 | 与上一行为同一批数据的早期导出，仅格式不同 |
| `process_logs/log_2026-10-1x.json`（8 个） | **由源码常量生成** | 非程序运行时产物，**不作为过程证据**，见 CORRECTION |
| `process_logs/telemetry_2026-11-09.log` 起 | 程序运行时逐条追加 | 每行携带前一条 SHA-256，改一行即断链 |
| `user_feedback.md` | 交流整理稿 | 评价内容真实；"使用 N 天"为同学自述，无逐日使用记录支撑 |

遥测链校验方式：

```bash
cd 02-20Days-Challenge/课题04-校园生活费记账工具
node src/verify_chain.js     # 正常应输出 [PASS] 并给出链头；被改动则报 hash 不匹配
```
