### 02-20Days-Challenge（20天挑战）

#### 课题04：校园生活费记账工具
- **痛点**: 大学生消费零散，难以掌握资金流向
- **解决方案**: 轻量化命令行记账工具，零安装、双击即用
- **核心功能**:
  - 记账/批量记账/删除/修改
  - 日/周/月统计报表
  - 预算提醒与异常消费提醒
  - 消费趋势图（ASCII可视化）
  - 补记功能（支持指定日期）
  - 数据导出（CSV/JSON备份）
  - Telemetry运行日志（8天102条记录）
- **技术栈**: Node.js（原生实现，无第三方依赖）
- **文件结构**:
  ```
  课题04-校园生活费记账工具/
  ├── main.js          # 核心程序
  ├── app.js           # CLI入口+交互菜单
  ├── 记账.bat         # 桌面快捷方式
  ├── README.md        # 项目说明
  ├── user_feedback.md # 8位用户反馈
  ├── process_logs/    # 8天Telemetry日志
  ├── raw_data/        # 原始消费数据
  └── data/            # 本地存储（不上传）
  ```
- **使用方法**:
  ```bash
  # 交互菜单
  node app.js menu
  
  # 或直接双击 记账.bat
  
  # 查看帮助
  node app.js help
  ```
